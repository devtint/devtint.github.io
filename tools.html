About

I am a security researcher with a strong interest in how systems break and how to make them more resilient. My research spans web application security, API security and the security of AI powered applications, and I build open source tools and Telegram bots to support that work.

I approach security from the fundamentals: how the web and networks actually work, where authentication and authorization tend to go wrong, and how to explain risk clearly to the people responsible for fixing it. Alongside my studies I practice responsible disclosure and have reported issues to universities, institutions and companies.
